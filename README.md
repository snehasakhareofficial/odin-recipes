# odin-recipes
The Odin Project - project 1 - HTML basics

## Introduction
This project is a basic recipe website created as part of The Odin Project Foundations curriculum. It consists of a main index page with links to multiple recipe pages built entirely using HTML.

## Skills Demonstrated
By completing this project, I practiced:
- Creating HTML documents
- Using headings, paragraphs, lists, and images
- Creating links between multiple pages
- Organizing project files
- Using Git for version control and GitHub for project hosting

## Reflection
This project strengthened my understanding of HTML fundamentals and website structure. I also gained more confidence using Git to track changes throughout the development process.
